# Siddharth Soni — AI Engineer Portfolio

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Files
- `index.html` — responsive portfolio with interactive particle background and scroll reveals.
- `assets/siddharth-soni.jpg` — cropped original portrait photo.
- `assets/siddharth-3d-character.png` — full-body character artwork, with CSS float and pointer-responsive 3D tilt.

## Before publishing
- Add your current résumé as `Siddharth_Soni_Resume.pdf` in the root folder (the Résumé links expect this filename).
- Verify project demos and social links are still active.
- Replace any metrics or experience details that you want to update.
- Deploy the folder to GitHub Pages, Netlify, Vercel static hosting, or your existing web host.
